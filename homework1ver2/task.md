Структуризация кода

Созданный ранее код необходимо структуризировать:

обернуть соответствующие блоки кода в class, struct, enum
создать необходимые func, использовать модификаторы доступа, вычисляемые переменные, extension и протоколы

За ориентир подхода к применению новых знаний по Swift рекомендуется брать практическую часть из урока
