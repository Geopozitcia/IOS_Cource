Необходимо в Xcode создать новый проект iOS-приложения и сверстать на Storyboard экран отображающий UI какого-либо торгового приложения (можно взять любое из интернета в качестве референса).

Не нужно полностью копировать дизайн, достаточно взять минимум подходящий для текущего ТЗ.

Основные требования:

использовать как минимум 5 разных UI-компонентов (среди них должна быть одна кнопка с текстом «Run» или каким-то аналогичным тайтлом)
использовать StackView в горизонтальном и вертикальном варианте (StackView не идет в зачет первого пункта с 5 компонентами)
создать View вложенное в другое UIView (либо любым другим образом отобразить вложенность subviews)
создать UIView, которое вычисляет свои размеры на основе внутреннего контента (данная View должна быть отличной от предыдущего пункта, то есть, суммарно должно быть 2 view с вложенными subview, одна из которых вычисляет свой размер на основе внутреннего контента)
Рекомендую не усложнять интерфейс, так как следующее задание будет сложнее и связано с вашей текущей реализацией, поэтому стоит придерживаться необходимого минимума.

----

Необходимо взять интерфейс из предыдущего задания и сверстать аналогичный UI на frame, с небольшими изменениями.

Допустимо отбросить несколько UIView, ради упрощения работы, но обязательно должны остаться - кнопка "Run" (или её аналог), View с вложенным View, 1 из вариантов StackView.


UI должен быть гибким и одинаково хорошо выглядеть и на iPhone 17 Pro и на iPhone SE

Для кнопки необходимо добавить соответствующее действие, запускающее работу “бота”.

Если текущая реализация не содержит каких-либо больших лейблов, чтобы отобразить работу “бота”, где можно уместить многострочный текст, то можно заменить часть UI или добавить текст (UILabel) фоном.

То есть вывод текста на экран каким-либо способом приоритетнее чем полное копирование предыдущего экрана на Storyboard.

В зависимости от вашей реализации, как альтернативой UILabel может быть UITextView, который умеет работать с длинным текстом помещая его в скролл.
